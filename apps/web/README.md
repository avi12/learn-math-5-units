# לוח מתמטיקה — your-site.web.app

לוח כתיבה בעט לטאבלט, שמשתקף בזמן אמת למסך המחשב. הכפתור המרכזי מעתיק את מה שכתבת
כתמונה, כדי להדביק ישירות בשיחה עם קלוד או לשלוח למורה.

**https://your-site.web.app**

## איך משתמשים

1. פותחים את הכתובת במחשב. מופיע קוד QR.
2. סורקים אותו פעם אחת מהטאבלט — שני המכשירים נכנסים לאותו חדר, והחדר נשמר בדפדפן
   של שניהם, כך שבפעמים הבאות פשוט פותחים את הכתובת.
3. כותבים בטאבלט. הכתב מופיע במחשב תוך כדי.
4. **העתק כתמונה** → מדביקים.

הכלים: עט בלחיץ (עובי לפי לחץ העט), ישר, מלבן, מעגל, ארבעה צבעים, ביטול אחרון וניקוי.
דחיית כף יד פעילה: אחרי שהעט נגע במסך, מגע אצבע מתעלם למשך שנייה וחצי.

## למה אין המרה ל‑LaTeX

זו הייתה הכוונה המקורית, וההחלטה הייתה לוותר עליה בשלב הזה. הסיבה מעשית: היעד הוא לשלוח
לקלוד, וקלוד קורא כתב יד מתמטי ישירות מהתמונה. המרה אוטומטית הייתה מחייבת מפתח API,
פונקציית שרת כפרוקסי ותוכנית Blaze בתשלום — וגם הייתה מחייבת אותך להגיה LaTeX שאתה עוד
לא קורא בשטף, כלומר להוסיף נקודת כשל במקום להסיר אחת.

**להוסיף בהמשך:** `src/lib/ink.ts` כבר מייצא את הקנבס כתמונה; צריך רק קובץ אחד שמעביר את
ה‑PNG ל‑Mathpix או ל‑Claude ומחזיר מחרוזת. ראו `Surface.exportCanvas()`.

## פריסה

```
npm run deploy
```

מפרסם דרך Hosting REST API עם טוקן קצר‑מועד מ‑`gcloud auth print-access-token`, כדי לא
לדרוש `firebase login` ולא להשאיר מפתח שירות על הדיסק. אחרי `firebase login` חד‑פעמי אפשר
גם `npm run deploy:cli`.

הסקריפט מתרגם את `firebase.json` לסכמה של ה‑REST API, כך שהקונפיגורציה נשארת במקום אחד
ושתי דרכי הפריסה לא יכולות להיפרד זו מזו.

## ארכיטקטורה

| רכיב | מה הוא עושה |
|---|---|
| `src/lib/ink.ts` | מודל הקו, אריזה למחרוזת, וציור. הקואורדינטות מנורמלות לרוחב הלוח, ולכן קו שנכתב בטאבלט 2560px נראה זהה בפאנל 900px. |
| `src/lib/room.ts` | Firebase, ומזהה החדר שמשותף לשני המכשירים. |
| `src/lib/Surface.svelte` | הקנבס. אותו רכיב משמש גם ככלי כתיבה וגם כמראה (`readonly`). |
| `src/App.svelte` | בחירת תפקיד, סרגל כלים, QR וייצוא. |
| `src/lib/cyberpunk.css` | העתק של `~/.claude/artifact-cyberpunk.css`. אתר לא יכול לקרוא משם בזמן בנייה, ולכן זה עותק — אם הסקין משתנה שם, להעתיק שוב. |

### סנכרון

- `rooms/{room}/strokes/{id}` — קווים שהושלמו. נדחפים פעם אחת בסיום הקו.
- `rooms/{room}/live` — הקו שבאמצע הכתיבה, נדרס כל 60ms ונמחק בסיום.
- `rooms/{room}/presence/{device}` — מי מחובר, נמחק אוטומטית בניתוק.

הפרדת `live` מ‑`strokes` היא מה שמאפשר תצוגה חיה בלי לכתוב לבסיס הנתונים על כל תזוזה
של העט: הקו הזמני נדרס במקום, והקו הסופי נשמר פעם אחת.

### אבטחה — במפורש

**אין התחברות.** ה‑API הניהולי של Firebase Auth דורש חשבון חיוב, וזה כלי אישי בתוכנית
החינמית. במקום זה:

- מזהה החדר הוא 128 ביט אקראיים מ‑`crypto.getRandomValues`.
- החוקים (`database.rules.json`) אוסרים קריאה או רשימה בכל מה שמעל `rooms/$room`,
  ומחייבים מזהה באורך 32 תווים. נבדק: קריאת השורש נדחית, וכתיבה לחדר בשם קצר נדחית.
- המזהה לא מתפרסם בשום מקום — הוא עובר בין שני המכשירים שלך בלבד.

זה מספיק לפנקס טיוטות אישי, וזה לא מספיק למשהו רגיש. **לחיזוק:** להפעיל Anonymous
sign‑in בקונסולה של Firebase, ואז להוסיף `auth != null &&` לשני התנאים בקובץ החוקים.
